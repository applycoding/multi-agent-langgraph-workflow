# Agent roles

This note is part of the local search corpus for the portfolio demo.

The planner turns a topic into a short research plan. The researcher reads tool hits from the web search stub and from local markdown. The writer drafts a briefing from those notes. A reviewer critiques the draft, and a person approves or rejects it.

LangGraph keeps the shared state for every role. Human approval is the gate before the structured report is final.
